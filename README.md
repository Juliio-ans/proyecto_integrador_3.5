## Controles

| Tecla | Función |
| --- | --- |
| `Espacio` | Iniciar o detener |
| `W`, `A`, `S`, `D` | Avanzar, izquierda, retroceder, derecha |
| `1` | Animación caminar |
| `2` | Animación correr |
| `3` | Animación saludar (tercera secuencia) |
| `Q` | Girar 90° a la izquierda |
| `E` | Girar 90° a la derecha |
| Arrastrar el ratón | Girar la cámara alrededor del personaje |
| Rueda del ratón | Acercar o alejar la cámara |
| Botón Música | Iniciar o pausar la pista sonora |
